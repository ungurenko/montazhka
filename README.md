# 🎬 Монтажка

Простая и лёгкая монтажка для Mac. Открывается мгновенно, всё по-русски, ничего лишнего:
добавил клипы → увидел звуковую волну → вырезал паузы (сам или автоматикой) → сохранил MP4.

## ✨ Что умеет

- **Клипы на одной ленте** — как бусины на нитке: режь, удаляй, меняй местами
- **Звуковая волна на каждом клипе** — паузы видно глазами
- **Автопоиск пауз** — программа сама находит тишину и подсвечивает её; ты проверяешь галочками и вырезаешь одной кнопкой
- **Умный монтаж речи** — находит оговорки, фальстарты, дубли и явные повторы; каждую будущую склейку можно прослушать до применения
- **Нарезка на shorts** — выбери длинное видео, ИИ найдёт сильные моменты и предложит ролики до 60 секунд; сохраняй пачкой MP4 в исходном формате, с вырезом 9:16 или целиком на чёрном/белом вертикальном фоне
- **Точное выделение** — поставь начало и конец, прослушай фрагмент и вырежи его целиком
- **Настройки поиска**: чувствительность (дБ), минимальная длина паузы, «воздух» по краям
- **Экспорт в MP4** — три уровня качества, прогресс, «Показать в Finder»
- **Всё сохраняется само** — как в Заметках; исходные видео никогда не изменяются
- **Переподключение файлов** — если исходник перенесли, проект остаётся целым и просит указать новое место
- **Отмена всего проекта** — Cmd+Z / Shift+Cmd+Z возвращает монтаж и настройки

## 🧠 Как работает умный монтаж

- Русскую речь локально расшифровывает Parakeet TDT 0.6B v3 через Core ML. При первом запуске модель загружается один раз и занимает около 460 МБ.
- Для анализа текста можно выбрать OpenRouter, Codex CLI или OpenCode CLI. Приложение само находит установленные CLI-агенты и загружает доступные им модели.
- У OpenRouter доступны Qwen 3.7 Flash, DeepSeek V4 Flash 0731 и GPT‑5.6 Luna. Codex CLI и OpenCode CLI показывают актуальные модели подключённого аккаунта.
- Звук, видео и пути файлов остаются на Mac. Выбранный AI-провайдер получает текст расшифровки с номерами слов и таймкодами; он может содержать произнесённые личные данные.
- Каждый вариант проходит два ИИ-прохода и локальную проверку тихих границ. Явные безопасные исправления отмечаются заранее, смысловые повторы всегда ждут ручной галочки.
- Все выбранные правки применяются одним действием и целиком возвращаются одним `Cmd+Z`.

Функция требует Mac с Apple Silicon. Для OpenRouter нужен [ключ](https://openrouter.ai/settings/keys), он хранится локально в папке данных Монтажки с доступом только текущему пользователю macOS. Для Codex CLI или OpenCode CLI достаточно установленного и авторизованного агента. Базовый редактор и экспорт работают на Intel и Apple Silicon.

## ✂️ Как работает нарезка на shorts

- Работает с отдельным длинным видеофайлом, проект не нужен. Кнопка «Нарезать на shorts» на стартовом экране.
- Расшифровка — та же локальная Parakeet, кэш транскриптов переиспользуется. Только русская речь.
- Длинные видео анализируются окнами по 15 минут с перекрытием: проход-предложение ищет сильные моменты в каждом окне, затем проход-отбор ранжирует кандидатов и отклоняет слабые. Выбранному AI-провайдеру передаются только метаданные и текст фрагментов.
- Критерии сильного ролика: цепляющее начало, законченная мысль без контекста, эмоция, инсайт или польза. Длительность каждого — до 60 секунд.
- Границы резов локально выравниваются по тихим точкам, чтобы фраза не обрывалась на полуслове.
- Пользователь выбирает число роликов (3 / 5 / 8 / авто); лучшие отмечаются галочками сразу, каждого можно просмотреть в плеере.
- Экспорт пачкой MP4 в выбранную папку с пикером качества и тремя форматами: исходный, вырез 9:16 или весь кадр на чёрном/белом фоне.
- Автоматические субтитры строятся по той же локальной расшифровке; их можно включить или выключить, выбрать стиль («Классика», «Акцент», «Подложка») и размер.

## 🤖 Управление через AI-агентов

Кнопка «Подключить AI-агентов» на стартовом экране устанавливает локальную
команду `montazhka`, регистрирует компактный MCP в Codex и Claude Code и добавляет
им тонкий скилл. После подключения агенты монтируют видео в отдельном процессе:
окно приложения не открывается, а длительную работу можно продолжить по `jobId`.

Доступны обычный и динамичный монтаж речи, точные внешние резы, улучшение голоса,
музыка, пять shorts 9:16 с субтитрами, проверка склеек, черновой и подтверждённый
финальный экспорт. Исходники не меняются. Полный контракт и примеры находятся в
[`docs/AGENT-API.md`](docs/AGENT-API.md) и [`scripts/agent-examples.sh`](scripts/agent-examples.sh).

Диагностика после подключения: `montazhka doctor`.

| Клавиша | Действие |
|---|---|
| Пробел | Плей / пауза |
| S | Разрезать по курсору |
| I / O | Поставить начало / конец выделения |
| X | Вырезать выделенный фрагмент |
| Delete | Удалить выбранный клип |
| ← / → | Кадр назад / вперёд (с Shift — секунда) |
| Cmd+Z | Отменить |

## 🔧 Для разработчика (и AI-агентов)

Нативное приложение: Swift 6 + SwiftUI + AVFoundation, macOS 14+. SwiftPM-сборке достаточно Command Line Tools; UI-тестам, архивированию и notarization нужен полный Xcode.

```bash
./scripts/bootstrap-tools.sh                  # XcodeGen, SwiftLint и actionlint закреплённых версий
./scripts/lint.sh                             # actionlint + swift-format + SwiftLint
./scripts/test.sh                             # все модульные тесты на Swift Testing
./scripts/build-app.sh                        # локальная .app со стабильной подписью
./scripts/build-app.sh --universal            # локальная universal .app
./scripts/build-app.sh --adhoc                # временная подпись для локальной диагностики
./script/build_and_run.sh                     # собрать, обновить /Applications и запустить
MONTAZHKA_SELFTEST_TIMEOUT=30 .build/release/Montazhka --selftest
.tools/xcodegen generate                      # Montazhka.xcodeproj для Xcode и UI-тестов
```

Готовое приложение находится в `build.noindex/Монтажка.app`. `script/build_and_run.sh` также заменяет копию в `/Applications`, чтобы при разработке всегда запускалась свежая версия.

### Публичный релиз

Релизная сборка — universal (`arm64` + `x86_64`), с Hardened Runtime, подписью Developer ID Application, notarization и Gatekeeper-проверкой:

```bash
MONTAZHKA_SIGNING_IDENTITY="Developer ID Application: …" NOTARY_KEYCHAIN_PROFILE=montazhka ./scripts/release.sh 1.1.0 2
```

Скрипт создаёт ZIP и SHA-256 в `build.noindex/release`, но сам ничего не публикует. Публичная загрузка выполняется отдельным ручным workflow `Release` в GitHub Actions. Нужные имена secrets перечислены прямо в `.github/workflows/release.yml`.

App Sandbox пока намеренно выключен: прямой канал распространения использует Developer ID и notarization, а включение sandbox требует отдельной миграции существующих данных из Application Support. Решение и обязательные меры защиты зафиксированы в [`docs/ADR-0001-direct-distribution-without-sandbox.md`](docs/ADR-0001-direct-distribution-without-sandbox.md).

### Архитектура

```
Sources/
├── MontazhkaExecutable/    # тонкий host: GUI или --selftest
└── Montazhka/              # единая библиотека MontazhkaKit
    ├── Core/               # модели проекта, операции ленты и история правок
    ├── AppEntry.swift      # единая точка входа для SwiftPM и Xcode-host
    ├── App.swift           # SwiftUI-приложение и навигация
    ├── Models/             # версионное JSON-хранилище проектов
    ├── Engine/
    │   ├── EditorController    # связывает интерфейс с отдельными сервисами
    │   ├── MediaPipeline       # единая сборка предпросмотра и экспорта
    │   ├── CompositionBuilder  # склейка клипов и понятные предупреждения
    │   ├── SpeechTranscriber   # Parakeet/Core ML и кэш расшифровки
    │   ├── SmartEditService    # два AI-прохода и безопасные решения
    │   ├── TranscriptTimelineMapper # обезличенные слова и координаты ленты
    │   ├── WaveformStore       # звуковая волна и кэш
    │   ├── SilenceDetector     # поиск пауз
    │   ├── Exporter            # сохранение MP4
    │   ├── ShortsController    # экран нарезки: анализ, просмотр, экспорт
    │   ├── ShortsCutService    # оконные проходы LLM и ранжирование роликов
    │   ├── ShortsWindowPlanner # окна транскрипта и разбор пересечений
    │   ├── ShortsBoundaryResolver # тихие границы начала и конца ролика
    │   ├── ShortsExporter      # экспорт ролика и форматы 9:16
    │   ├── ShortsVideoComposition # вырез/вписывание, фон и offline-рендер
    │   └── ShortsSubtitles     # настройки, фразы и слой субтитров
    ├── Views/                  # редактор, лента и панели инструментов
    └── SelfTest/               # сквозная самопроверка на сгенерированном видео
Tests/MontazhkaTests/        # миграции, монтаж, медиасборка и умный монтаж
Tests/MontazhkaUITests/      # Xcode UI smoke-тест доступности стартового экрана
```

Ключевые принципы:
- Исходники не трогаем: клип = ссылка на файл + границы (start/end)
- Любая правка = снимок всего проекта в историю → пересборка композиции → автосохранение (0.5 сек дебаунс)
- Проекты: `~/Library/Application Support/Montazhka/Projects/*.json`
- Кэш волн: `~/Library/Application Support/Montazhka/Waveforms/*.f32`
- Кэш расшифровок: `~/Library/Application Support/Montazhka/Transcripts/*.json`
- Модель Parakeet: `~/Library/Application Support/Montazhka/Models/`
