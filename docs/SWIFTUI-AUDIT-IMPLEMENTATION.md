## Оставшиеся ограничения проверки

1. **GUI XCTest не запустился.** Runner сообщил `Timed out while enabling automation mode`. Системный журнал уточнил: `Writer daemon requires authentication to enable automation mode`. Для запуска требуется действие пользователя: подтвердить системную аутентификацию UI Automation при запуске `./scripts/test-ui.sh`. Разрешения TCC и DevToolsSecurity не изменялись.
2. **Native drag мышью не воспроизведён.** CUA возвращал `noWindowsAvailable` на координатные действия, хотя AX-действия и осмотр интерфейса работали. Поэтому успешный drop, Esc во время drag, drop вне окна и изменение клипов во время native drag остаются без GUI-подтверждения. Логика временного порядка, единственный Undo и защита от устаревшего снимка прошли автоматические тесты. Успешный drop и drop вне окна добавлены в GUI-набор.
3. **Обрезка короткого первого клипа мышью после зума не проверена в окне.** Исправление сравнения `pps` и геометрия проверены кодом/тестами; обрезка через доступное действие воспроизведена. Удержание H при смене фокуса и пробел в модальном диалоге покрыты тестами области действия, без полного ручного сценария. После закрытия системного диалога CUA потерял AX-доступ; диагностическая выборка показала главный поток в обычном ожидании событий, а не доказанное зависание приложения.
4. **Озвучивание VoiceOver и canvas Xcode Preview не запускались.** Проверены дерево доступности, доступные действия и тесты изоляции зависимостей превью. Реальный анализ через платные провайдеры/CLI не выполнялся; готовность трёх провайдеров проверена с подменёнными зависимостями.
5. **Совместимость macOS 14 проверена сборкой и доступностью API.** Исполнение проверялось на текущем Mac с macOS 27 / Xcode 27, отдельного устройства с macOS 14 не было.
