# 🎬 Montazhka Agent API v1

## Быстрый выбор

1. Вызвать `montazhka_doctor`.
2. Для обычного разговорного ролика выбрать `clean-speech`.
3. Для более плотного темпа выбрать `dynamic`.
4. Для пяти вертикальных роликов с субтитрами вызвать `montazhka_make_shorts`.
5. Читать состояние долгой задачи через `montazhka_get_job waitSeconds=25` — вызов сам ждёт смены этапа.
6. Проверить проект через `montazhka_inspect`, затем сделать компактный черновик.
7. Если пользователь поручил готовый файл — вызвать финальный `montazhka_export`.

## Двенадцать MCP-инструментов

| Инструмент | Назначение |
|---|---|
| `montazhka_doctor` | Проверка движка, модели и папок |
| `montazhka_get_projects` | Список или один проект |
| `montazhka_edit_video` | Полный монтаж по профилю |
| `montazhka_make_shorts` | Анализ и пять вертикальных роликов |
| `montazhka_edit_project` | Точные резы и настройки в копии проекта |
| `montazhka_get_job` | Короткий статус по `jobId`, с `waitSeconds` — ожидание смены этапа |
| `montazhka_inspect` | Лента: клипы с номерами, время ленты и исходника, ревизия; до 200 клипов, дальше `nextOffset` |
| `montazhka_transcript` | Слова с номерами и временем ленты, паузы, склейки, отпечаток `timeline`; поиск `query` |
| `montazhka_frames` | Сетка кадров картинкой: диапазон, точные моменты или «до/после» склеек |
| `montazhka_audio` | Громкость по отрезкам (dBFS) и тишины |
| `montazhka_apply_edits` | Правки ленты: deleteWords, delete, split, move, trim, insert, undo |
| `montazhka_export` | Черновой или финальный MP4 с проверкой длительности |

Большие ответы не входят в обычный вызов. Транскрипт, кандидаты, отчёт и итог
фоновой работы читаются по адресам `montazhka://runs/{jobId}/{artifact}`.

## Профили

- `clean-speech`: длинные паузы, осторожные речевые исправления, улучшение голоса, без музыки.
- `dynamic`: более короткие паузы, те же осторожные смысловые правила.
- `shorts`: до пяти роликов 9:16, классические субтитры, компактное качество.

Точные внешние резы имеют поля `sourcePath`, `start`, `end`. Корректные диапазоны
применяются буквально, без сдвига к словам и тишине.

`aiMode="built-in"` включает встроенный смысловой монтаж.
`aiMode="external"` создаёт копию проекта, возвращает расшифровку и ждёт точные
резы через `montazhka_edit_project`. Если модели ещё нет, агент повторяет вызов с
`confirmModelDownload=true` только после подтверждения.

## Самостоятельный монтаж

Инструменты «глаз, ушей и ножниц» работают во времени ленты проекта — в секундах
итогового ролика. `montazhka_frames` и `montazhka_audio` вместо проекта принимают
`filePath`: так агент проверяет готовый MP4.

- `montazhka_transcript` — строки `#номер начало конец слово`, отметки `--- пауза ---` и
  `--- склейка ---`, до 1500 слов за вызов, продолжение с `nextFrom`, отпечаток ленты `timeline`.
  `query` возвращает до 30 совпадений фразы: номера слов `from`/`to`, время и контекст (регистр,
  «ё» и знаки препинания не важны, слово запроса совпадает с началом слова). Если расшифровки
  ещё нет, вызов запускает её в фоне и возвращает `jobId`.
- `montazhka_frames` — одна JPEG-сетка до 16 кадров с таймкодами. `from`+`to`+`count`
  дают равномерные кадры (узкий диапазон — приближение), `times` — точные моменты,
  `aroundCuts=true` — пары «до/после» каждой склейки проекта. В MCP картинка приходит
  прямо в ответе, в CLI — путём `imagePath`.
- `montazhka_audio` — `levelsDB` по `buckets` равным отрезкам (до 200), `loudestDB`,
  тишины от 0,4 секунды.
- `montazhka_apply_edits` — операции выполняются по порядку:

| Операция | Поля | Что делает |
|---|---|---|
| `deleteWords` | `words[{from,to}]`, `timeline` | Вырезает слова по номерам из `transcript`; рез ложится в тишину между словами. `timeline` должен совпадать с текущей лентой |
| `delete` | `ranges[{from,to}]` | Вырезает куски; все диапазоны считаются по ленте до операции |
| `split` | `at` | Разрезает клип в точке |
| `move` | `clip`, `to` | Переставляет клип на новое место (номера из `inspect`) |
| `trim` | `clip`, `edge` (`start`/`end`), `seconds` | Подрезает край; отрицательное число удлиняет в пределах исходника |
| `insert` | `sourcePath`, `start`, `end`, `at` | Вставляет кусок любого исходника (время файла) в точку ленты |
| `undo` | `steps` | Отдельным вызовом возвращает предыдущую ревизию |

Каждая правка сохраняет ревизию в `~/Library/Application Support/Montazhka/AgentRevisions`.
Ответ содержит новую ленту (до 50 клипов, `clipsShown`) и предупреждения: рез посреди слова,
новый кусок короче 0,25 секунды. После любой правки номера слов и клипов меняются — перед
следующим `deleteWords` снова вызовите `transcript`.

Если проект открыт в окне Монтажки, окно подхватывает правку агента в течение секунды и
показывает «Агент изменил проект»; пользователь может вернуть прежнюю версию. Окно больше
не перезаписывает файл, который изменил агент.

Порядок работы: `edit_video` → `inspect` → `transcript` → `frames`/`audio` в сомнительных
местах → `apply_edits` → `frames aroundCuts=true` → финальный `export` → проверка готового
файла через `frames`/`audio` с `filePath`.

## CLI

CLI возвращает один JSON-объект версии 1 в stdout. Диагностика: `montazhka doctor`.
Основные команды: `projects`, `edit-video`, `edit-project`, `make-shorts`, `job`,
`inspect`, `transcript`, `frames`, `audio`, `apply-edits`, `export`, `integration`.
Кадры и звук: `--project <id>` или `--file <mp4>`, `--from`, `--to`, `--count`,
`--times 1.5,3`, `--around-cuts`, `--buckets`. Поиск по расшифровке — `transcript --query "фраза"`,
ожидание задачи — `job --id <jobId> --wait 25`, страницы ленты — `inspect --offset 200 --limit 200`. Правки: `montazhka apply-edits --project <id>
--request ops.json` (список операций или `{"operations": [...]}`), отмена — `--undo [шаги]`. Для сложного пакета: `montazhka edit-project --request request.json`.
Во встроенном ИИ через CLI используется `--smart-edit`, во внешнем — `--external-ai`.

Существующий выходной файл сохраняется. Перезапись возможна только с явным
`--overwrite`. Финальный экспорт требует одновременно `--final --confirm-final`;
просьба пользователя «смонтируй и сделай готовый файл» — достаточное согласие.
Без `outputPath` финал ложится рядом с исходником как `<имя>-montazhka.mp4`,
черновик — как `<имя>-montazhka-draft.mp4`. Итог экспорта содержит `durationCheck`.

## Версия сервера

`montazhka_doctor` возвращает `version` (версия, сборка, коммит) и `serverStale`. Сервер MCP живёт
столько же, сколько сессия агента. Если приложение переустановили после её старта, каждый ответ
содержит `warnings` с просьбой перезапустить сессию: до этого агенту видны старые инструменты.
При запуске приложение само обновляет скилл `montazhka` у подключённых агентов.

## Восстановление

Состояние хранится в `~/Library/Application Support/Montazhka/AgentRuns`.
После закрытия агента новый сеанс продолжает проверку по тому же `jobId`.
Ошибка содержит код, понятное сообщение и, когда возможно, способ восстановления.

Если модели нет, умный монтаж и shorts возвращают `MODEL_DOWNLOAD_REQUIRED` и примерный размер.
Повторный вызов с `confirmModelDownload=true` разрешает загрузку. Совместимая
Parakeet Core ML-модель в известной папке используется на месте.

## Обязательная проверка результата

- Все исходники доступны.
- Длительность и дорожки распознаны.
- Точные резы входят в исходники.
- Кадры «до/после» склеек просмотрены через `montazhka_frames aroundCuts=true`.
- Финальный MP4 существует, `durationCheck.matches` равно `true`.
- Кадры и громкость готового MP4 проверены через `filePath`.
- Исходные видео не изменились.
