# 🎬 Montazhka Agent API v1

## Быстрый выбор

1. Вызвать `montazhka_doctor`.
2. Для обычного разговорного ролика выбрать `clean-speech`.
3. Для более плотного темпа выбрать `dynamic`.
4. Для пяти вертикальных роликов с субтитрами вызвать `montazhka_make_shorts`.
5. Читать состояние долгой задачи через `montazhka_get_job`.
6. Проверить проект через `montazhka_inspect`, затем сделать компактный черновик.
7. После явного «ОК» вызвать финальный `montazhka_export`.

## Восемь MCP-инструментов

| Инструмент | Назначение |
|---|---|
| `montazhka_doctor` | Проверка движка, модели и папок |
| `montazhka_get_projects` | Список или один проект |
| `montazhka_edit_video` | Полный монтаж по профилю |
| `montazhka_make_shorts` | Анализ и пять вертикальных роликов |
| `montazhka_edit_project` | Точные резы и настройки в копии проекта |
| `montazhka_get_job` | Короткий статус по `jobId` |
| `montazhka_inspect` | Длительность, файлы и зоны склеек |
| `montazhka_export` | Черновой или подтверждённый финальный MP4 |

Большие ответы не входят в обычный вызов. Транскрипт, кандидаты, отчёт и итог
фоновой работы читаются по адресам `montazhka://runs/{jobId}/{artifact}`.

## Профили

- `clean-speech`: длинные паузы, осторожные речевые исправления, улучшение голоса, без музыки.
- `dynamic`: более короткие паузы, те же осторожные смысловые правила.
- `shorts`: до пяти роликов 9:16, классические субтитры, компактное качество.

Точные внешние резы имеют поля `sourcePath`, `start`, `end`. Корректные диапазоны
применяются буквально, без сдвига к словам и тишине.

`aiMode="built-in"` включает встроенный смысловой монтаж.
`aiMode="external"` создаёт копию проекта, возвращает расшифровку и ждёт точные
резы через `montazhka_edit_project`. Если модели ещё нет, агент повторяет вызов с
`confirmModelDownload=true` только после подтверждения.

## CLI

CLI возвращает один JSON-объект версии 1 в stdout. Диагностика: `montazhka doctor`.
Основные команды: `projects`, `edit-video`, `edit-project`, `make-shorts`, `job`,
`inspect`, `export`, `integration`. Для сложного пакета: `montazhka edit-project --request request.json`.
Во встроенном ИИ через CLI используется `--smart-edit`, во внешнем — `--external-ai`.

Существующий выходной файл сохраняется. Перезапись возможна только с явным
`--overwrite`. Финальный экспорт требует одновременно `--final --confirm-final`.

## Восстановление

Состояние хранится в `~/Library/Application Support/Montazhka/AgentRuns`.
После закрытия агента новый сеанс продолжает проверку по тому же `jobId`.
Ошибка содержит код, понятное сообщение и, когда возможно, способ восстановления.

Если модели нет, умный монтаж и shorts возвращают `MODEL_DOWNLOAD_REQUIRED` и примерный размер.
Повторный вызов с `confirmModelDownload=true` разрешает загрузку. Совместимая
Parakeet Core ML-модель в известной папке используется на месте.

## Обязательная проверка результата

- Все исходники доступны.
- Длительность и дорожки распознаны.
- Точные резы входят в исходники.
- Фрагменты вокруг склеек проверены.
- Компактный черновик открывается и играет.
- Финальный MP4 существует и имеет ожидаемую длительность.
- Исходные видео не изменились.
