# ADR-0001: прямая дистрибуция без App Sandbox

- Статус: принято
- Дата: 2026-08-20

## Контекст

Монтажка распространяется напрямую через GitHub Releases. Приложение хранит проекты, кэши волн, расшифровки и локальные модели в `~/Library/Application Support/Montazhka`, работает с выбранными пользователем видео и вызывает локальные Core ML-модели. Включение App Sandbox сейчас изменит пути контейнера и потребует отдельной миграции уже существующих данных.

## Решение

Текущая ветка релизов остаётся без App Sandbox. Каждый публичный артефакт обязан:

- собираться как universal binary для `arm64` и `x86_64`;
- подписываться сертификатом Developer ID Application с Hardened Runtime;
- проходить notarization, stapling и локальную проверку Gatekeeper;
- сохранять security-scoped bookmarks для выбранных пользователем медиа и держать доступ только на время работы с файлом;
- хранить ключ OpenRouter только в Keychain.

Основной редактор поддерживает Intel и Apple Silicon. Локальные функции расшифровки и ИИ-монтажа доступны только на Apple Silicon из-за зависимости от Core ML-модели FluidAudio.

## Последствия

GitHub Releases остаётся единственным каналом публичной доставки. App Store и sandboxed-дистрибуция не заявляются. Переход к App Sandbox оформляется отдельным решением с миграцией данных, проверкой всех media-пайплайнов и новым релизным циклом.
