# 🧹 Упрощение кода: Монтажка

**Дата аудита:** 2026-09-04
**Что за проект:** десктопное приложение для macOS на Swift/SwiftUI (Swift Package Manager,
Swift 6), 140 файлов исходников, ~25 000 строк. Искал по профилю «десктоп».
**Чем сканировал:** чтением кода и grep, тремя параллельными разведчиками по участкам; каждая
находка перепроверена лично. Готовых инструментов для Swift (детекторы дублей и мёртвого кода)
не применял — их в проекте нет, всё найдено по коду.
**Статус плана:** 11 из 13 сделано.

## 📊 Общий вердикт

🟡 **Проект чистый, но с повторами.** Мёртвого кода почти нет, обе внешние библиотеки реально
используются, отладочного мусора и закомментированного кода не осталось. Вся лишняя сложность
была одного вида: одно и то же правило, записанное в нескольких местах. Убрано около 200 строк
повторов; главное — каждое такое правило теперь живёт в одном месте.

## 🚫 Не трогать (и почему)

- **Протоколы с «единственной реализацией»** (`ProjectRepository`, `AICompletionServing`,
  `VideoExporting`, `ExportPreparing`, `ShortsPreviewBuilding`, `TranscriptProviding`,
  `WaveformProviding`) — *у каждого есть тестовый дублёр в `Tests/`. Обобщение оправдано.*
- **`ShortsSubtitles.swift` (866 строк)** — *правила отрисовки субтитров: шрифты, переносы,
  подсветка слова, миграция старых стилей. Сложность самого предмета, а не лишняя.*
- **`peakSlice` в `ShortsBoundaryResolver` и `SmartCutBoundaryResolver`** — *выглядят одинаково,
  но отличаются округлением. Слияние сдвинуло бы границы нарезки.*
- **`TimeFormat` и `ShortsCutService.clock`** — *форматирование для интерфейса и для промпта
  модели: разные потребители, меняются по разным причинам.*
- **Хранилище расшифровок в агент-слое остаётся явным** — *внутри него живёт загруженная модель
  распознавания; вычисляемое свойство пересоздавало бы её в цикле.*
- **Самотесты `SelfTest*`** — *живой инструмент, запускается флагом `--selftest`.*
- **`PreviewCatalog.swift`** — *превью для Xcode под `#if DEBUG`.*
- **`script/` рядом со `scripts/`** — *путаное соседство, но `script/build_and_run.sh` прописан
  в `README.md` и во внешней настройке `.codex/environments/environment.toml`.*
- **Минимальная версия macOS в `Package.swift` и `project.yml`** — *XcodeGen не читает
  `Package.swift`, дублирование неизбежно.*
