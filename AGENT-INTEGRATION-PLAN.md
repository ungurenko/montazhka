# 🎬 Интеграция AI-агентов — реализованная архитектура

**Версия контракта:** 1
**Основной справочник:** [`docs/AGENT-API.md`](docs/AGENT-API.md)

Старый план с Whisper и набором разрозненных CLI-команд больше не действует.
«Монтажка» предоставляет общий невидимый движок, компактный локальный MCP и
запасной JSON CLI. Окно приложения при агентском монтаже не запускается.

Актуальные принципы:

- восемь MCP-инструментов и большие материалы через `montazhka://`;
- долгие операции живут в отдельных фоновых процессах и продолжаются по `jobId`;
- проекты и состояние задач сохраняются в Application Support;
- точные диапазоны внешнего агента применяются в координатах исходника;
- существующий проект сначала копируется, исходные видео не меняются;
- черновик создаётся без подтверждения, финальный экспорт — только после «ОК»;
- подключение Codex и Claude Code выполняет кнопка в приложении.

Этот файл оставлен как короткий указатель, чтобы старые ссылки не вели к
устаревшему Whisper/CLI-плану.
